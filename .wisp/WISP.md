# Wisp project overlay

This project speaks `wisp.handoff.v1` ([INTEROP.md](../INTEROP.md)).

## Every session

1. Read `research/HANDOFF.md` first.
2. Read the newest `research/sessions/*.md` (including `cursor-*`).
3. Use `search_memory` on `.wisp/memory/` for locked facts.
4. Prefer bundled skill names: `literature-review`, `analysis-workflow`,
   `singlecell-qc`, `pdf-explore`, `public-data-access`, `figure-composer`,
   `paper-narrative`, `local-env-setup`.
5. Persist results as project files. Kernel variables are not visible to Cursor.

## Before you stop

Update `research/HANDOFF.md` (`last_app: wisp`, `next`, `key_files`).
Write `research/sessions/wisp-YYYY-MM-DD-topic.md`.
Write short facts to `.wisp/memory/`.

Say “read HANDOFF and continue” after a Cursor session. Chat bubbles do not sync.
