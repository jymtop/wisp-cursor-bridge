# Figure composer (Cursor adapter)

Write Python 3.12 plotting scripts under `research/scripts/` or the analysis module `scripts/`. Save PNG/SVG under `research/figures/` or `output/figures/`.

- One script produces the figure. Record the command in HANDOFF.
- Prefer existing project style if `figure-style` notes exist.
- Inspect the image after render. Do not claim a figure you did not write to disk.
- `/canvas` is only for interactive demos, not the archival figure.
