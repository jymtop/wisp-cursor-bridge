# PDF explore (Cursor adapter)

Adapted from Wisp `pdf-explore`.

1. Use Cursor file tools to locate PDFs under the project (never leave the workspace).
2. Extract tables, numbers, and methods claims with citations to page or section.
3. Flag contradictions instead of guessing.
4. Write a structured note to `research/notes/` and update HANDOFF.

Do not fetch paywalled PDFs unless the user already placed the file in the project.
